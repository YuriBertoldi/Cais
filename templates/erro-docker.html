Verificações rápidas

Execute no PowerShell, nesta ordem. A primeira que falhar indica onde está o problema.

wsl -l -v
wsl -d {{.Distro}} -- systemctl status docker --no-pager
wsl -d {{.Distro}} -- curl -s --unix-socket /var/run/docker.sock http://localhost/_ping
curl.exe -s http://127.0.0.1:2375/_ping

Se o teste pelo socket Unix funciona mas o último falha, o daemon está de pé e o problema é a exposição em TCP — confira o drop-in do systemd em /etc/systemd/system/docker.service.d/override.conf.
